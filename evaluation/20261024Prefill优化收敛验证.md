## 已实现

1. 目标异步 guard=0 路径复用上一轮整个 chunk 的实际 immutable-prefix 选择作为 feedback，不保留最后一个 Query 重新评分。空集合与无预测区分；反馈仍在 forward 完成后更新。host-backed feedback 只更新请求内已有 runtime plan，不把上一请求的选择发布为下一请求冷启动 plan。
2. 下一层预测 H2D 从 correction 尾部移到已有 decoder-layer release callback：记录当前层 release event，先提交下一层 H2D，再用同一 event 提交当前层必要 D2H。消费端仍仅等待实际使用的数据。
3. `swap_blocks()` 使用经过 int64/[N,2] 校验的 CPU accessor，支持非连续 mapping stride，保留双端连续合并规则与 D2D 顺序。H2D helper 直接接收已有 CPU pairs，只构造一次 native mapping，移除 Tensor-to-list 往返。
4. 现有 runner 支持 output=1 的完整 layer/chunk 验证；增加评分次数、feedback 复用/重评分和 CPU copy 提交成本统计。

- prompt=32768，output=1，batch=1，B=16，budget=32，chunk=1024，window=4，lead=1，guard=0，RoPE position cache=33792。每点预热 3 次、正式 10 次，串行运行。

## Nsight 与 copy 成本

本轮单独运行 Nsight 成功，生成完整 nsys-rep/SQLite；没有与 GPU 测试并行，也未将 profiling 样本纳入性能统计。复用已有 overlap 分析脚本，按正式 request、worker PID/TID、CUDA correlationId、layer NVTX 范围和模型 GEMM/Attention kernel 核对。统计 H2D 字节与同一 profiling 请求的 worker mapping 字节完全一致。

| 点 | 实际 KV H2D 字节 | GPU H2D 时间 ms | 与模型计算交集 ms | 下一层预取与当前层计算交集 ms |
| --- | --- | --- | --- | --- |
| 16K/16K | 601358336 | 75.7514 | 2.1906 | 2.1906 |
| 32K/0 | 257622016 | 35.0688 | 0 | 0 |

16K 确实出现了真实重叠，但比例小；32K 仍未出现。16K 的 48 笔预测 DMA 中 46 笔在 Python helper 返回前已完成，32K 为 48/48。只能说明这些 copy 很短、可隐藏窗口有限，不能把 API 异步当成充分重叠，更不能宣称所有场景预取验收通过。前者不代表 helper 做了 CPU event synchronize。

copy 微测直接使用现有 swap_blocks，单次 256 x 32 KiB，预热 5、采样 50，CPU mapping 在计时前构造，GPU 初始化同步仅存在于诊断脚本。CPU 提交 p50（checkpoint -> 最终，ms）：H2D 连续 1.0911 -> 0.0066，非连续 2.1988 -> 0.4383；D2H 连续 1.0942 -> 0.0064，非连续 2.1962 -> 0.4274；有序 D2D 连续 1.9298 -> 0.6612，非连续 1.9284 -> 0.6614。保留原映射字节数与 D2D 顺序。CUDA event span 含 CPU enqueue 空隙，不将其当作纯 DMA 时间；纯 copy 执行时长以 Nsight 表为准。

## 结论与限制

- 三项计划内实现完成；保持原 sparse 算法、容量、32 KiB layout 与正确性约束，未新增 fallback 或全量恢复。
- 正确性与既有小样本质量门禁通过。六点 output=1 TTFT 中位数相对 checkpoint 均降低，两点 output=2 首次 decode 中位数也降低。
- 真实重叠仅在 16K/16K 观测到少量；32K/0 为零。因此完整预取重叠目标未全面达成，不能标记全部成功。
- 28K/31K output=1 含排空 p95 未改善，现有样本还不足以证明所有场景不存在可重复尾延迟回退。31K/32K 仍慢于当前 Dense。所有不利结果保留。
- 不追加新的预取器、队列、缓存或同步绕过上述限制。下一轮如需继续，应先针对现有实际 Selection、冷恢复和排空成本确认瓶颈，由用户验收后决定。
