## 本轮修改

- 在已有 `_get_prediction_representatives()` 增加可选 keyword-only `device`，集中迁移和保留 page-scoped GPU metadata，实际历史初始化与 predictor 共用，不逐请求重新上传相同 prefix representative。
- 已注册 logical indices 排序唯一，按历史边界裁剪使用 prefix view，不构造索引张量重新 gather 相同 metadata。请求私有封块增量仍通过既有 append 路径生成，不修改共享 prefix。
- CUDA 异步 predictor 复用已有固定容量选择与 pinned 控制 buffer，不再把 GPU Query 搬到 CPU scoring，不调用 CUDA `.tolist()` 或动态长度 `nonzero()`。
- complete history 与 immutable prefix 边界不一致时，仍按原预测候选边界重新 scoring。没有删除 actual feedback 的候选/预算/Query guard，也没有宣称所有重复评分已消除。
- 新增 GPU 测试覆盖跨请求共享 metadata 复用，以及最后 prompt token 为 partial history 时 predictor 的候选边界、结果与设备一致性。

本轮恢复、copy、owner、backing、kernel、native、布局和调度未改。目标 selected-list 的现有恢复仍为：写前只保护旧 partial tail；Query 后只恢复 `history_blocks` 中 GPU 缺失的 immutable prefix 和生成历史。实际 mapping 的独立来源分类记录尚未补全，不能把函数审计及端到端 parity 说成已完成全部逐笔流量验收。
