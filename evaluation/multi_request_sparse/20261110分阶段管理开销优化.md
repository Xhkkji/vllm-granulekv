## 2026-11-13 编号转换、轮询清理与 READY 回收修正

本轮在上述 CPU 管理优化基础上完成三项局部修改，**尚未 commit 或 push**：

本节更新上文关于“READY 发布链路尚未修改”和“本轮两处修改”的阶段性描述；以下结果以本节实现和复测为准。

3. 将 runtime 已有事件取出和终态确认抽为内部 drain。Worker 完成本轮所有 native/host 轮询后再 drain 一次，返回后段刚产生的事件；这次 drain 不发起新 I/O 或激活窗口。
