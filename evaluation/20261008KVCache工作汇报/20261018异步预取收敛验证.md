## 测试准备问题

1. 结束的 populate 请求局部 metadata 已清理，runner 改为通过稳定 page identity 发布短前缀 metadata。
2. `max_tokens=64` 原来允许 EOS 提前结束，性能测试现固定输出长度。
3. 准备阶段原来生成 64 token，resident prefix cache 会留下完整 generated blocks。step=16 时 reference 的 logical block 2048 从 physical 2051 替换为 2048，前 15 个已计算 token 的 KV 发生变化。checkpoint 与第一阶段对这份污染 trace 的失败位置及差异计数完全一致，不能归因为本轮 Selection 改动或 CPU Cache 损坏。
4. 准备统一只生成建立 metadata 必需的 2 token，不留下可复用的完整 generated block；重建 reference 后，64-token 严格回放完全对齐。不修改生产分配器或 backing 逻辑来掩盖测试问题。
