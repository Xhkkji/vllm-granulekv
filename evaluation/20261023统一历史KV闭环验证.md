# 统一历史 KV 选择与按需恢复：本地验证记录

日期：2026-10-22 至 2026-10-23。

## 当前结论

历史选择和按需恢复已在本地实现。16K/16K、32K/0 的 all-block Dense 对齐、固定选择跨路径回放及现有小样本质量初筛通过。性能门禁未通过：16K/16K 搬运量和耗时下降，但 32K/0 存在两轮可重复的性能回退。依照停止条件停止推进，不把本轮宣布为完整验收成功，不继续叠加预取或驻留机制。

## 实现范围

1. `SparseKVActualSelection` 统一为 `history_blocks` 和设备 Attention 选择，不保留旧 prefix 字段别名。
2. 对当前 chunk 开始前 C 个 token，完整历史 `[0, floor(C/B))` 都参与原有 scorer；init/local、每头预算、stable tie-breaking、GQA、chunk 内最高分归约不变。旧 partial tail 必选，当前 chunk 不进入历史 H2D。
3. 请求私有 representative 复用已有容器和 builder，在 XFormers 收尾、release fence 之前仅追加本轮新封满的 block；共享 immutable metadata 不被追加修改。没有回读已逐出的数据补 metadata。
4. worker 只选择一次。immutable 部分沿用既有 SSD/host staging correction；选中的生成历史走既有 backing 恢复。selected-list 路径不再自动拼入、恢复全部历史 suffix；写前只恢复必要的旧 partial tail。
5. XFormers workspace 直接组织选中历史及当前 chunk，保留原始 RoPE 位置和 bottom-right causal mask。resident reference 共用选择语义。
6. record/replay 明确使用 `complete_history_v1`，记录真实最终选择与历史边界；目标路径拒绝不满足新语义的旧 trace。
7. 保留已有 compact/backend 的原有行为，不为本轮新路径添加 fallback；不修改 native、CUDA kernel、32 KiB 布局或 copy 调度，不新增功能开关、全局同步或 CPU event synchronize。

## 停止原因与未完成项

32K/0 的性能回退已重复，不能认定“无回退”门禁通过。该点没有长 suffix，H2D 只增加 1.03%，因此不能将回退解释为再次全量恢复 suffix。已测 Selection 时间也增加，但还没有足够的分段证据将全部耗时差归因于某个函数。

静态检查后续应优先核对请求私有 representative 初始化时的 CPU→GPU metadata 转移，以及 32K 最后 prompt token 的完整历史/immutable 边界不同导致不能直接复用 actual selection 的 prediction feedback。它们是待分离计时的控制面成本，不能把推测当成已测根因，也不能通过删除 partial-tail、owner 或 backing 保护绕过。

依停止条件，本轮未继续扩展 24K/28K/30K/31K 四点的完整正确性回放矩阵、分层路径连续 decode 跨新封块的专用端到端回放，也未进行六点正式性能比较。增量封块的单元测试和 resident 小样本连续生成不能替代该专用跨路径测试。

本轮未实施固定 sink 物理分区、prediction keep、提前 H2D 或写回调度优化，未做新的 Nsight overlap 验收，不宣称真实提前预取重叠已经实现。后续应先定位并消除已复现的 32K 控制面回退，再补齐尚缺门禁；没有用户新授权不得提交或推送本地实现。
